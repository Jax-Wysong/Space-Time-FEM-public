A field-split outer / time-slab RAS inner (FS-RAS) preconditioner was implemented and compared against the existing time-slab RAS outer / field-split inner (RAS-FS) scheme. In FS-RAS the global residual vector is first split into the {\phi, u} and {\chi, v} field-block subproblems additively, and each 2-DOF block is then preconditioned independently by the custom time-slab RAS. This required assembling separate 2-DOF slab matrices via a new stiff2_block routine and maintaining two sets of slab objects per MPI rank. Despite the added implementation complexity, FS-RAS and RAS-FS produced identical GMRES iteration counts at every grid size and subdomain count tested. The equivalence is not coincidental: the linear Klein-Gordon operator is already block-diagonal in the {\phi, u}/{\chi, v} field partition, so the two orderings of the FS and RAS approximations commute and produce the same preconditioned operator. Because FS-RAS requires twice as many slab matrix/KSP/vector objects per rank, it incurs higher memory and temporal usage with no convergence benefit, making RAS-FS the preferable choice for this system.

A nonlinear preconditioner variant (slab_pc_nonlinear) that rebuilds the slab matrices using the current Newton iterate was also evaluated. The nonlinear Jacobian contributions from the Ghost potential V(\phi, \chi) enter the slab matrices as mass-matrix-type integrals scaling as O(V′′ hx ht), while the dominant spatial wave-operator stiffness scales as O(ht/hx). Their ratio is O(V′′ hx^2), which is on the order of 10⁻⁴ to 10⁻⁵ at the grid resolutions used, not because the potential is weak (|V′′| ≈ O(1) at the MMS solution), but because the second-order wave operator's principal symbol naturally dominates lower-order pointwise terms at fine scales. Consequently, the nonlinear PC produced no measurable reduction in GMRES iteration counts compared to the frozen-linear PC, while incurring significant additional factorization cost per Newton step. The same scaling argument implies that a Picard linearization (omitting V′′ from the assembled Jacobian entirely) would converge at essentially the same rate as full Newton for this problem at any practically useful resolution. We note that problems with stronger nonlinearities may produce different results and that RAS-FS / FS-RAS should be investigated in these regimes. In the problem here, it is possible to investigate a larger nonlinear contribution by making lam22 >> 1. In this regime, nonlinear updates will likely become desirable and/or neccesary.
